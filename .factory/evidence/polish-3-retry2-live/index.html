How it works

Replace only oversized allowed fields

  1. 01

    Choose exact fields

    Only configured JSON Pointers are considered.

  2. 02

    Encrypt, then store

    An AES-256-GCM envelope is written through an S3-compatible adapter.

  3. 03

    Leave a signed reference

    The reference records size, digest, field, redacted preview, and expiry.

API / v0.1.0

Configure four required options

Choose allowed fields, an inline limit, an object store, and a retention window.

  • Typed ESM, CommonJS, and declarations
  • No telemetry or runtime dependencies
  • Node 20+ with Web Crypto and fetch
npm install event-payload-spillway
const spillway = new Spillway({
  allowlist: ["/result/attachment"],
  maxInlineBytes: 32_000,
  store: new S3CompatibleStore(s3),
  encryptionKey,
  signingKey,
  expiresInMs: 604_800_000,
});
const handle = createSpillwayProxy({
  spillway,
  upstream: "http://automation:3000/events",
  verifyWebhook: ({ rawBody, headers }) =>
    verify(rawBody, headers),
});

Privacy and limits

What stays local and what this does not do

The Demo uses temporary browser memory. It sends no payload or telemetry. Spillway is not a queue, CDN, malware scanner, or legal-retention service. You configure production storage, keys, and retention.
