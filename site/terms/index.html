Use this library with your own safeguards

Event Payload Spillway is free, open-source software under the MIT License (external). The hosted site is documentation and a local demo.

What the library does

It encrypts selected oversized JSON values, stores them through your configured S3-compatible adapter, and leaves signed references in an event.

What it does not do

It is not a queue, general-purpose CDN, database proxy, malware scanner, backup service, or legal-retention system. Your event system remains responsible for delivery and retries.

Your responsibilities

Verify provider signatures before transformation. Protect retrieval URLs. Configure storage permissions, TLS, lifecycle rules, retention, and access controls for your environment.

Changes

Updates appear in the repository history. Continued use after an update means you use the current published version.
