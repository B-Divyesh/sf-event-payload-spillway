Policy / effective 28 August 2026

Demo data stays in your browser

Short version: the demo keeps its sample and any edits in temporary browser memory. It does not upload or retain payloads.

Information we collect

We do not use accounts, analytics, advertising pixels, cookies, or third-party scripts. Static hosting may process normal request logs for delivery and security.

Local processing

The demo creates temporary keys and encrypted objects with Web Crypto. It does not use localStorage, IndexedDB, or remote object storage for payloads. A service worker caches public site files, never form input.

Library users

The npm library has no telemetry. When you deploy it, choose your own object store, key handling, retention rules, logs, and privacy notice.

Your choices

Use Reset demo to restore the shipped sample. Clear public site files through your browser site-data controls. For repository questions, open an issue on GitHub (external).
