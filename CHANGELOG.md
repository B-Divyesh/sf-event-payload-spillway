# Changelog

All notable changes follow [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-08-27

- Initial typed ESM/CommonJS release.
- Add explicit JSON-pointer spill rules, AES-GCM encryption, signed references, restore, safe previews, and atomic rollback.
- Add in-memory and S3-compatible/MinIO storage adapters.
- Add raw-body-aware reverse proxy, expiry reports, dry-run reclaim, and legal holds.
- Add interactive local-first documentation site.
